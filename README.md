# Semantic_Web_Mosiienko_lab1
Для виконання роботи предметною областю було обрано відеоігри, з яких було обрано 5.\
Для предметної області було сформовано 5 питань:
1. Які ігри доступні на платформах PS5 та ПК?
2. Які розробники ігор обрали жанр First Person Shooter?
3. Яку кількість ігор розробили наявні студії?
4. Які компанії видавці випускали ігри на персональні комп'ютери?
5. Яка компанія видавець випустила найбільше ігор?\
Для заповнення графа було обрано:\
S.T.A.L.K.E.R.: Тінь Чорнобиля\
S.T.A.L.K.E.R. 2: Серце Чорнобиля\
Project Zomboid\
Metro 2033 Redux\
Відьмак 3: Дикий гін.\
Дані для заповнення графа було взято з Wikipedia.
# Основним файлом є Graphbuilder.ipynb
У ньому визначаються неймспейси та типи даних, створюються макети сутностей та заповнюється трійками граф.\
Після заповнення будується та зберігається візуалізація графу, серіалізується граф у формати Turtle та XML після чого виводяться певні трійки у консоль пов'язані з доступністю ігор та сутністю гри Project Zomboid.\
Також у останніх двох комірках файлу налаштовується зв'язок з зовнішнім RDF-графом Wikidata для ігор S.T.A.L.K.E.R.: Тінь Чорнобиля та Metro 2033 Redux для отримання дати їх випуску.
# SPARQL-запити
Для структуризації запити зберігаються у окремих Python файлах queue_1–queue_5 та виконують запити що відповідають на поставлені до предметної області питання.\
